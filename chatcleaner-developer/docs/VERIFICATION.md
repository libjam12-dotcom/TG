# Реально выполненные проверки

Дата: 29 октября 2026. Проверочная среда Python 3.12, Node.js. Внешние API и production не использовались.

- Python backend успешно импортирован на очищенной копии.
- Поднят локальный UI/API через dev/run.py: HTML и JS 200, /auth/me 200, /api/scanner/operations 200. Подключённых Telegram ID нет, заданий 0. После проверки процессы остановлены, созданная тестовая база удалена из передаваемого пакета.
- Чужой Host и чужой Origin на изменяющем запросе: 403.
- В offline-режиме внешнее DNS-имя и внешний IP отклонены до соединения. Это не проверка безопасности всей ОС.
- 76 Node-проверок интерфейса: PASS, включая ручной quick-mode, валидацию, безопасное сохранение, pause/reload и отображение причин. Вместо производственного job fixture создан полностью синтетический пример.
- test_manual_rpc_regression: PASS. Один синтетический BadRequestError с CHAT_MEMBER_ADD_FAILED сохраняет enum и InviteToChannelRequest, не делает повтор, оставляет следующего pending. Никакого реального добавления этот тест не подтверждает.
- Полный backend-набор после очистки: 1021 проверка, 8 явно пропущенных, 2 failure и 1 error. Один failure оказался нарушенной регистронезависимой подстановкой публичного имени бота; копия исправлена, этот тест отдельно повторён и PASS. Остальные два сбоя подтверждены также на исходной локальной копии, до очистки.

## Оставшиеся известные сбои (не скрыты)

1. test_owner_assistant.OwnerAssistantTests.test_public_source_resolved_in_own_session: fake SimpleNamespace без session; AttributeError. Нужно обновить fixture/контракт отдельной owner-подсистемы.
2. test_owner_assistant.OwnerAssistantTests.test_personal_limits_are_enforced_on_api_not_only_ui: ожидаемый HTTPException не получен. Требуется проверить серверную валидацию личных настроек. Это отдельная owner-подсистема, не доказательство работоспособности инвайтов.

Эти две проверки сохранены как падающие, не объявлены успешными и не отключены.

## Явно пропущенные восемь проверок

Семь test_file_import зависят от ZIP tdesktop-open/locked. Архивы сессий в передачу не включены; при необходимости разработчик генерирует свои синтетические fixtures. Ещё одна проверка сравнивает с отсутствующим старым deployment-файлом isolated_invite_campaign_v2.py. У этих восьми тестов явные unittest.skip с причиной, код проверок оставлен. Другие тесты импорта и инвайтов выполняются.

## Изменения тестового окружения

Абсолютные пути заменены переносимыми. Согласованы тестовые числовые ID и маркированные ID каналов. Начальные демонстрационные данные UI очищены. Устаревшая часть navigation-теста личного marketing без зависимостей исключена; scanner navigation проверяется. Личные community-тесты исключены вместе с личным модулем.

Не выполнено: свежая установка pip в новом окружении, визуальная браузерная приёмка всех страниц, реальные операции Telegram, приёмка production. Не считать отсутствие новых инвайтов ошибкой пакета: он поставляется с отключённым Telegram и внешней сетью по умолчанию.
