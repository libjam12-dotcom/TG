# Происхождение и различия

Дата снимка: 29 октября 2026. Основа — локальная рабочая копия клиентской Telegram-панели. Это НЕ экспорт работающего сервера и НЕ новый production release.

Сохранены Python/FastAPI/Telethon, SQLite, vanilla JavaScript, маршруты API и относительные имена модулей. Весь модуль ручного инвайтинга и связанные контроллеры переданы, чтобы разработчик мог менять сервер и интерфейс, а не только читать описание.

Идентификаторы людей/групп/аккаунтов, реальные профили и адрес панели заменены синтетическими. Специальные прежние сценарии, привязанные к фиксированным ID, в этой копии НЕ подключают настоящие группы и требуют собственной настройки тестовой среды. Сопоставление с оригинальными ID разработчику не передаётся.

Очищены начальные бизнес-записи UI. Личный OwnerHub представлен пустым совместимым адаптером; NeuroVlad, изображения, контент сообщества, реальные логи, старые deploy/install/backup-скрипты, исходная README с историей, docs/evidence и Git не передавались. Клиентские операции и зависимости сохранены. Тесты личного OwnerHub исключены вместе с его содержимым.

Локальный репозиторий содержит изменения, которые ещё не установлены на сервере, включая дополнительные диагностические ветки и последнюю правку сохранения безопасной metadata при BadRequestError. Нельзя считать весь пакет побайтово соответствующим production или устанавливать его целиком. Требуется review конечного diff и перенос только относящихся к задаче изменений.

`dev/run.py` и `dev/sitecustomize.py` добавлены для этой передачи, они не являются частью боевой авторизации. Production Nginx/auth/Cloud/systemd не передавались. В полном приложении backend доверяет заголовкам, которые в production должен выставлять проверенный reverse proxy; нельзя выставлять Python backend напрямую в интернет.

Зависимости приложения зафиксированы в `scanner/requirements.txt`. `dev/constraints-tested.txt` содержит версии установленных прямых и основных транзитивных зависимостей из проверочной Python-среды, не универсальный lock для всех ОС. Дополнительный вариант установки: `python -m pip install -r scanner/requirements.txt -c dev/constraints-tested.txt`. Подтверждено на Python 3.12; установка с нуля через pip в рамках этой передачи не выполнялась.

При сдаче обозначать: локальная реализация, автоматические тесты, проверка браузера и реальные добавления в Telegram — разные результаты. Производственные ошибки, чьи детали были утрачены, не восстанавливать предположениями.
