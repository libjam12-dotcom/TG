# Chatcleaner — очищенные исходники для ревью инвайтинга

Начните с [START-HERE.txt](START-HERE.txt): полное ТЗ для Qwen, DeepSeek или разработчика.

Исходники, инструкция запуска, тесты и ограничения находятся в [chatcleaner-developer](chatcleaner-developer/README.md).

Это отдельный очищенный снимок от 29 октября 2026, не production release. Рабочие аккаунты, сессии, базы, персональные списки, секреты и доступ к серверу не передаются. Идентификаторы заменены тестовыми. Сетевые обращения Python по умолчанию заблокированы локальным адаптером.

Известные сбои и непроведённые проверки перечислены в [VERIFICATION.md](chatcleaner-developer/docs/VERIFICATION.md). Результаты unit-тестов не подтверждают добавление людей в Telegram.
