# Chatcleaner — актуальный снимок сервера, 19 ноября 2026

Начните с [состояния и состава передачи](chatcleaner-developer/docs/CURRENT-STATUS-20261119.md), затем [запуска для разработчика](chatcleaner-developer/README.md).

Это очищенные исходники работающей клиентской Telegram-панели, полученные по SSH 19 ноября. Включены UI, сканер и операции, антиспам и сервер авторизации. Рабочие секреты, Telegram-сессии, базы и клиентские списки отсутствуют. Идентификаторы заменены тестовыми, личные материалы исключены.

Ветка `main` и работа программиста сохранены. Этот снимок показывает фактический сервер; он не объявляется исправленной версией. Известные ошибки инвайтинга описаны в документе состояния. Тесты и локальный адаптер унаследованы из main, а не с сервера.
